
## Markdown files extraction 

```text
In the directory "./WL" write a Wolfram Language (WL) script "PacletMarkdownFiles.wls" that for a given paclet directory <pacdir>:
- Finds the file names of all tech-note notebooks and function page notebooks of <pacdir>
- Converts all these noteboks to Markdown files
- Places those Markdown files in the subdiretory "Markdown-files" of paclet's directory <pacdir>

Use only WL built-in functions, do not use external packages or paclets.
```
